## "The Survivors"

Members of the scholarship community often jokingly referred to graduates of the Deep Reinforcement Learning Nanodegree as **"the survivors."**

Reinforcement learning is widely regarded as one of the most challenging areas of applied machine learning. The program required mastering:

* Deep Q-Networks (DQN)
* Experience Replay
* Target Networks
* Actor-Critic Architectures
* Deep Deterministic Policy Gradients (DDPG)
* Multi-Agent Reinforcement Learning
* Continuous Control
* PyTorch

The projects in this repository document that learning journey.

## Projects Included

| Project                        | Topic                 | Algorithm |
| ------------------------------ | --------------------- | --------- |
| 🍌 Banana Navigation           | Autonomous Navigation | DQN       |
| 🤖 Continuous Control          | Robotic Arm Control   | DDPG      |
| 🎾 Collaboration & Competition | Multi-Agent Learning  | MADDPG    |

### 🍌 Banana Navigation

Train an autonomous agent to navigate a Unity environment while maximizing cumulative reward through value-based reinforcement learning.

**Key concepts**

* Deep Q-Networks
* Experience Replay
* Target Networks
* Exploration vs Exploitation

---

### 🤖 Continuous Control

Train a robotic arm to continuously track target positions using continuous action spaces.

**Key concepts**

* DDPG
* Actor-Critic Architectures
* Continuous Control
* Robotic Manipulation

---

### 🎾 Collaboration & Competition

Train two autonomous agents to sustain cooperative tennis rallies within a shared environment.

**Key concepts**

* Multi-Agent Reinforcement Learning
* MADDPG
* Emergent Cooperation
* Distributed Decision Systems

## Why This Repository Matters

Although completed in 2019, these projects remain an important milestone in my development as an AI practitioner.

They document an early progression through three increasingly complex reinforcement learning paradigms:

```text
DQN
  ↓
DDPG
  ↓
MADDPG
```

from single-agent value learning,

to continuous control,

to multi-agent coordination.

Many of the concepts explored here continue to influence my later work in AI systems, autonomous decision architectures, agent-based systems, and applied machine learning.
